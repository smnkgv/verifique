The first release of verifique, a verification queue for coding agents.

Agents hand over their finished work and carry on. Each check runs when a slot is free, on its own copy of your app with its own ports and databases, and comes back with a verdict and proof.

Tested on real web apps and on native iOS and Android apps. It works with Claude Code today, and has a way to plug in other agents that hasn't been tried with one yet.

```bash
curl -fsSL https://raw.githubusercontent.com/smnkgv/verifique/main/install.sh | sh
```

The menu bar panel for macOS is built from source for now, because sharing it needs an Apple Developer ID.
